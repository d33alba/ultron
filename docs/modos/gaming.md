# Gaming

Activa el escritorio de neón con `ultron entrar gaming`. El HUD de ejemplo funciona
aunque el equipo carezca de sensores o biblioteca de juegos.

| Ejemplo | Salida |
|---|---|
| `ultron juegos --demo` | Biblioteca de ejemplo con títulos de Steam, Lutris y Flatpak. |
| `ultron juegos 1` | Inicia el primer título de tu biblioteca. |
| `ultron hud --demo --una-vez` | Panel de CPU, RAM, GPU, disco, red y XP. |
| `ultron turbo estado` | Estado del perfil de rendimiento. |
| `ultron fps on` | Confirmación de que el contador se activó para los juegos lanzados desde Ultron. |
| `ultron clip` | Indica si pudo armar la grabación de clips. |
| `ultron clip guardar` | Ruta al clip guardado. |
| `ultron clip parar` | Confirmación de parada de la grabación. |
| `ultron visualizador` | Barras de audio en la terminal mediante cava. |
| `ultron perfil` | Nivel, experiencia, estadísticas y logros. |
| `ultron gaming fondo --semilla 2077` | Ruta al fondo generado. |

La grabación depende de las herramientas disponibles y del permiso de captura de
pantalla en GNOME. `ultron salir` restaura las capas.

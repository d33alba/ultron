# Focus

Activa el escritorio de estudio con `ultron entrar focus`. Los comandos de lectura
usan IA cuando necesitan redactar. Los datos de estudio y los mazos se guardan en tu
directorio XDG. Las salidas de esta tabla describen lo que verás.

| Ejemplo | Salida |
|---|---|
| `ultron resumen tema.pdf` | Resumen del documento. |
| `ultron flashcards tema.pdf` | Tarjetas generadas y nombre del mazo. |
| `ultron flashcards lista` | Tabla de mazos guardados. |
| `ultron flashcards exportar biologia` | Ruta al paquete Anki. |
| `ultron flashcards borrar biologia` | Confirmación de eliminación del mazo. |
| `ultron repasar --demo` | Preguntas, respuestas e intervalo del próximo repaso. |
| `ultron examen tema.pdf` | Preguntas, correcciones y nota. |
| `ultron pregunta tema.pdf "¿Qué es una célula?"` | Respuesta con referencias de página. |
| `ultron esquema tema.pdf --png esquema.png` | Esquema y ruta a la imagen exportada. |
| `ultron explica "fotosíntesis"` | Explicación adaptada al nivel elegido. |
| `ultron plan añadir Biología 2026-12-03` | Confirmación con el identificador del evento. |
| `ultron plan lista` | Lista de eventos e identificadores. |
| `ultron plan ver` | Calendario por días. |
| `ultron plan hoy` | Bloques de estudio de hoy. |
| `ultron plan quitar ID` | Confirmación tras quitar el evento indicado. |
| `ultron pomodoro --sin-bloqueo` | Cuenta atrás por sesiones y descansos. |
| `ultron pomodoro webs` | Dominios configurados para bloqueo. |
| `ultron stats --demo` | Mapa de calor y horas de ejemplo. |

Usa `ultron salir` para restaurar el escritorio.
